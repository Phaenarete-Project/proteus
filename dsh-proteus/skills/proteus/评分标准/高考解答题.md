# 高考解答题评分模板（12 分制）

用途：写 `ExamContract.grading_rubric`，或对照 `proteus_grade` 输出核对分数。**模板不是官方评分细则**：`source` 一律先填 `"inferred"`；能拿到官方细则再改 `"official"`，并保留本模板作为兜底。

## 通用约束（四个模板都适用）

1. `Σ step_points[].points + answer_points = total_points`，容差 0.001（§2.1 `POINTS_SUM` 是 error 级）。
2. 每步必须有 `id`、`desc`、`points ≥ 0`、`evidence`（枚举 `structural`/`numeric`/`symbolic`/`formal`/`human`），`id` 不可重复。**v0.1 只有 `numeric` 与 `structural` 有生产者**：`numeric_residual`/`expression_sample`/`domain_probe` 全产 `numeric`，`answer_format` 产 `structural`。因此本文件的 `evidence` 一律写 `numeric` 或 `structural`；写 `symbolic`/`formal` 会让该步永远拿不满。
3. `required: true` 的步骤在缺证据时按 `partial` 折算：`all_or_nothing` → 0，`half_on_missing` → 0.5×points，`proportional` → 0.5×points×已验种类/要求种类（§2.5-1）。
4. `structural` 证据由 `proteus_grade` 内部生成（`step.text` 非空即 pass），**不计入 `independent_kinds`**（§2.3）。
5. `deduction_rules` 的 `trap` 必须取自 T01–T24；写不在库里的 `trap` 视为配置错误，不扣分。**陷阱是否适用看文本门槛，不看 `domain`**：T19 要求题面/givens 出现「独立/条件概率/`P(AB)`」，T23 要求出现「级数/收敛/发散」——只有 `domain=probability/series` 不足以触发，照抄本文件不会误扣。
6. 答案分 `answer_points` 只保护「最终答案的形式与正确性」；过程分一律走 `step_points`。
7. 每张步骤表最后一列「建议 tags」是该步应带的 tag：**漏贴会触发对应陷阱扣分**（如 S1 漏 `domain` 会被 T01 扣 2 分，线代题漏 `rank` 会被 T22 扣分），所以正确解答也要贴。tag 是对评分者的声明，必须与正文一致；详见 `陷阱库.md` 与 `SKILL.md` §5。

## 模板 A｜导数：单调性与极值（12 分）

**题面模板**：设 `f(x)=x^3-3x`（可换成含参 `f(x)=x^3+ax^2+bx`），求 `f` 的单调区间与极值。

**契约要点**

```jsonc
{ "exam": "gaokao-math", "domain": "calculus", "problem_type": "computation",
  "knowledge_points": ["GK.FUNC.MONO", "GK.FUNC.EXTREMUM"],
  "goal": { "kind": "evaluate", "statement": "求 f 的单调区间与极值" },
  "answer_format": { "type": "interval" },
  "grading_rubric": { "source": "inferred", "total_points": 12, "answer_points": 2,
    "step_points": [
      { "id": "S1", "desc": "写出定义域", "points": 2, "required": true,
        "evidence": ["structural"], "partial": "all_or_nothing" },
      { "id": "S2", "desc": "求导并写出 f'(x)", "points": 3, "required": true,
        "evidence": ["numeric"], "partial": "half_on_missing" },
      { "id": "S3", "desc": "解 f'(x)=0 并逐区间判号", "points": 3, "required": true,
        "evidence": ["numeric"], "partial": "proportional" },
      { "id": "S4", "desc": "写出单调区间与极值结论", "points": 2, "required": true,
        "evidence": ["structural"], "partial": "half_on_missing" } ],
    "deduction_rules": [ { "trap": "T01", "deduct": 2 }, { "trap": "T09", "deduct": 2 } ] } }
```

| 步 | 踩分点写法（照抄这句就有分） | 分 | evidence | partial | 建议 tags |
|---|---|---|---|---|---|
| S1 | 「函数 `f(x)` 的定义域为 `R`。」（若为分式/根式/对数，写出解集） | 2 | structural | all_or_nothing | domain |
| S2 | 「`f'(x)=3x^2-3=3(x-1)(x+1)`。」必须**先求导再因式分解** | 3 | numeric | half_on_missing | uses:G1 |
| S3 | 「令 `f'(x)=0` 得 `x=-1` 或 `x=1`。当 `x<-1` 时 `f'(x)>0`；当 `-1<x<1` 时 `f'(x)<0`；当 `x>1` 时 `f'(x)>0`。」 | 3 | numeric | proportional | cases:3 |
| S4 | 「`f(x)` 在 `(-∞,-1]`、`[1,+∞)` 上单调递增，在 `[-1,1]` 上单调递减；极大值 `f(-1)=2`，极小值 `f(1)=-2`。」 | 2 | structural | half_on_missing | — |
| Ans | `answer.value = "增区间(-∞,-1)和(1,+∞)；减区间(-1,1)；极大值2，极小值-2"` | 2 | — | — | — |

**合计核对**：`2+3+3+2 = 10`，`10 + answer_points(2) = 12` = `total_points` ✓

**允许跳步**：`f'(x)` 的因式分解过程、解二次方程的过程可略；区间端点的开闭可只在一处声明。**不可跳**：定义域（S1）、`f'(x)` 的显式表达式（S2）、判号理由（S3）、结论句（S4）。

**常见扣分**：T01 定义域遗漏 −2；T09 区间端点开闭错误 −2；T13 中间步骤用 `≈` 导致精度不足 −1；含参题 T08 参数范围未讨论 −2。

**如何对照 `proteus_grade`**：看 `step_scores[].earned` 是否逐条对上；若 `S2.earned = 1.5` 说明只有一类证据 pass（`half_on_missing`/`proportional` 生效），应回到 S4 补 `proteus_verify run`。

## 模板 B｜数列：通项与求和（12 分）

**题面模板**：已知数列 `{a_n}` 满足 `a_1=1`，`a_{n+1}=2a_n+1`（或给出 `S_n` 与 `a_n` 的关系），求 `a_n` 与前 `n` 项和 `T_n`。

**契约要点**：`domain: "series"`，`knowledge_points: ["GK.SEQ.RECUR","GK.SEQ.SUM"]`，`problem_type: "computation"`，`answer_format.type: "expression"`，`total_points: 12`，`answer_points: 2`。

| 步 | 踩分点写法 | 分 | evidence | partial | 建议 tags |
|---|---|---|---|---|---|
| S1 | 「由 `a_{n+1}+1=2(a_n+1)`，得 `{a_n+1}` 是首项 `2`、公比 `2` 的等比数列，故 `a_n=2^n-1`。」构造 + 通项一体给分 | 3 | numeric | half_on_missing | uses:G1 |
| S2 | 「`T_n=Σ_{k=1}^{n}(2^k-1)=Σ2^k-n`。」写出求和结构（拆项/错位/裂项的名称或等价变形） | 2 | numeric | all_or_nothing | — |
| S3 | 「`Σ_{k=1}^{n}2^k=2^{n+1}-2`，故 `T_n=2^{n+1}-n-2`。」代入求和公式并化简 | 3 | numeric | proportional | — |
| S4 | 「取 `n=1` 验证：`T_1=1` 与 `a_1=1` 一致；取 `n=2` 验证 `T_2=4=1+3`。故结论成立。」 | 2 | numeric | half_on_missing | — |
| Ans | `answer.value = "a_n=2^n-1, T_n=2^(n+1)-n-2"` | 2 | — | — | — |

**合计核对**：`3+2+3+2 = 10`，`10 + 2 = 12` ✓

**允许跳步**：等比求和公式的推导可略；`n=2` 的代入可只写一行。**不可跳**：构造辅助数列的等式（S1）、求和结构的说明（S2）、`n=1` 的检验（S4）——这是数列题最容易被扣的「不检验」。

**常见扣分**：T18 分类不当（如 `q=1` 未单独讨论）−2；T08 含参通项未分类 −2；T13 中途取近似 −1；T15 使用了未定义的 `T_n`/`S_n` 记号 −1。**高考数列不涉及级数收敛，不适用 T23**（T23 需题面/步骤出现「级数/收敛/发散」）。

## 模板 C｜解析几何：椭圆与直线（12 分）

**题面模板**：椭圆 `x^2/4+y^2=1` 与过点 `P(0,1)` 的直线 `l` 交于 `A`、`B`，求 `|AB|` 或 `△OAB` 面积的最值。

**契约要点**：`domain: "geometry"`，`knowledge_points: ["GK.ANALYTIC.ELLIPSE","GK.ANALYTIC.LINE"]`，`problem_type: "computation"`，`answer_format.type: "expression"`（或 `interval`），`total_points: 12`，`answer_points: 2`。

| 步 | 踩分点写法 | 分 | evidence | partial | 建议 tags |
|---|---|---|---|---|---|
| S1 | 「① 当 `l` 斜率不存在时，`l: x=0`，与椭圆交于 `(0,±1)`，弦长 `AB=2`。② 当 `l` 斜率存在时，设 `l: y=kx+1`，代入 `x^2/4+y^2=1` 得 `(1+4k^2)x^2+8kx=0`。」**必须讨论斜率不存在** | 3 | numeric | half_on_missing | domain, cases:2 |
| S2 | 「设 `A(x_1,y_1)`、`B(x_2,y_2)`，则 `x_1+x_2=-8k/(1+4k^2)`，`x_1x_2=0`。」写出韦达定理 | 3 | numeric | proportional | — |
| S3 | 「由对称性不妨设 `k>0`；弦长 `AB=√(1+k^2)·√((x_1+x_2)^2-4x_1x_2)=√(1+k^2)·8k/(1+4k^2)`。」把题设目标代数化 | 2 | numeric | half_on_missing | — |
| S4 | 「令 `AB^2=g(k)=64k^2(1+k^2)/(1+4k^2)^2`，求导得 `k=1/2` 时 `g` 取最大值，故 `AB` 的最大值为 `√5`。」 | 2 | numeric | proportional | — |
| Ans | `answer.value = "弦长 AB 的最大值为 √5"`（以实际题为准） | 2 | — | — | — |

**合计核对**：`3+3+2+2 = 10`，`10 + 2 = 12` ✓

**允许跳步**：联立消元的中间展开、求导找最值的求导过程可略写。**不可跳**：斜率存在性讨论（S1 的一半分）、韦达定理（S2）、弦长 `AB` 的代数表达式（S3）。

**常见扣分**：T01/T05 未讨论斜率不存在或 `1+4k^2≠0` −2；T08 参数未分类 −2；T09 最值处区间端点开闭错 −2；T15 直接用 `A`、`B` 不设坐标 −1；T07 漏另一解 −2。

## 模板 D｜概率统计：分布列与期望（12 分）

**题面模板**：袋中有 3 个红球、2 个白球，不放回取 2 次，每次取 1 个，`X` 为取到的红球数，求 `X` 的分布列、`E(X)`、`D(X)`。

**契约要点**：`domain: "probability"`，`knowledge_points: ["GK.PROB.DISTRIBUTION"]`，`problem_type: "computation"`，`answer_format.type: "expression"`，`total_points: 12`，`answer_points: 2`。

| 步 | 踩分点写法 | 分 | evidence | partial | 建议 tags |
|---|---|---|---|---|---|
| S1 | 「`X` 的可能取值为 `0,1,2`。」写全取值并说明依据（`X` 的定义） | 2 | structural | all_or_nothing | cases:3 |
| S2 | 「`P(X=0)=C(2,2)/C(5,2)=1/10`；`P(X=1)=C(3,1)C(2,1)/C(5,2)=6/10`；`P(X=2)=C(3,2)/C(5,2)=3/10`。检验：`1/10+6/10+3/10=1`。」逐项计数 + 归一化检验 | 4 | numeric | proportional | — |
| S3 | 「`E(X)=0×1/10+1×6/10+2×3/10=6/5`。」 | 2 | numeric | half_on_missing | — |
| S4 | 「`E(X^2)=0+6/10+12/10=9/5`，`D(X)=9/5-(6/5)^2=9/25`。」 | 2 | numeric | half_on_missing | — |
| Ans | `answer.value = "分布列 P(X=0)=1/10, P(X=1)=3/5, P(X=2)=3/10; E(X)=6/5; D(X)=9/25"` | 2 | — | — | — |

**合计核对**：`2+4+2+2 = 10`，`10 + 2 = 12` ✓

**允许跳步**：组合数展开过程可略；`E(X^2)` 可一步写出。**不可跳**：取值集合（S1）、逐项概率（S2）、归一化检验（S2 结尾）、`D(X)` 的计算式（S4）。

**常见扣分**：T18 计数重复/遗漏（不放回当放回）−2；T13 中途取小数 −1；T07 漏取值 −2；T06 题面有单位而未带 −1；T16 选出干扰项（选择题）−2。**本题不放回、题面未提独立性，不适用 T19**（T19 需题面/givens 出现「独立」「条件概率」或 `P(AB)`）。
