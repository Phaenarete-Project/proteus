# 陷阱库（T01–T24，与 INTERFACES.md §6.1 完全一致）

陷阱是「在纯数学上不算错、但在评分标准下要扣分」的结构化判定项。`proteus_grade` 只对 `basis="rule"` 的 `TrapFinding` 扣分；`basis="heuristic"` 的 finding 只进 `traps[]`、进 `notes`，**不进 `deductions`**（§2.5 计分规则第 4 条）。

## T01 定义域遗漏

- **severity** / **默认扣分**：`major` / 2
- **触发条件**：`contract.domain ∈ {calculus, geometry}` 且 `solution.steps` 中**没有任何** step 的 `tags` 含 `domain`。
- **检测依据**：`contract.domain`；`steps[].tags`。
- **正确写法**：第一个步骤显式给出定义域并打 tag。
  `{"id":"S1","text":"函数 f(x)=x^3-3x 的定义域为 R。","tags":["domain"]}`
- **反例（高考）**：求 `f(x)=x^3-3x` 的单调区间，解答从「`f'(x)=3x^2-3`」开始，全程不写定义域。
- **反例（考研）**：计算 `∫_0^2 dx/(x^2-1)`，不声明 `x=±1` 为瑕点、不做区间分割，直接用牛顿-莱布尼茨。

## T02 绝对值分类讨论不全

- **severity** / **默认扣分**：`major` / 2
- **触发条件**：`problem.text` 或任一 `givens[].text` 命中下列任一触发符——半角竖线 `|`、全角竖线 `｜`、中文「绝对值」——且所有 `cases:N` tag 中最大的 `N < 2`。**只看题面与 `givens`，不看 `steps` 文本**（步骤里写绝对值是正常的，不构成触发）。
- **检测依据**：`problem.text`、`givens[].text` 中的 `[|｜]` 与「绝对值」；`steps[].tags` 里的 `cases:N`。
- **正确写法**：每个零点把数轴切成独立一支，N 等于分支数，每支写清区间与表达式。
  `{"text":"当 x<1 时，|x-1|=1-x；当 x>=1 时，|x-1|=x-1。","tags":["cases:2"]}`
- **反例（高考）**：求 `f(x)=|x-1|+|x+2|` 的最小值，只讨论 `x≥1` 一支就给出 `3`。
- **反例（考研）**：解 `|x-2| < x+1`，直接移项平方，忽略 `x+1<0` 时无解的分支。

## T03 对数定义域遗漏

- **severity** / **默认扣分**：`major` / 2
- **触发条件**：`problem.text`、`givens[].text` 或任一 `step.text` 含 `ln` / `log` / `lg`，且无 `domain` tag。
- **检测依据**：文本正则；`steps[].tags`。
- **正确写法**：先写真数大于 0 的定义域，再变形。
  `{"text":"由真数 x>0 得定义域 (0,+∞)。","tags":["domain"]}`
- **反例（高考）**：`f(x)=ln x - ax ≤ 0` 对 `x>0` 恒成立求 `a`，解答直接从求导开始，不写 `x>0`。
- **反例（考研）**：求 `y=ln(x^2-1)` 的单调区间，把定义域写成 `R\{±1}` 之外或直接 `R`。

## T04 偶次根号定义域遗漏

- **severity** / **默认扣分**：`major` / 2
- **触发条件**：文本含 `sqrt` 或 `√`，且无 `domain` tag。
- **检测依据**：文本正则；`steps[].tags`。
- **正确写法**：写出被开方式 `≥ 0` 的解集后再继续。
  `{"text":"由 x-1>=0 得定义域 [1,+∞)。","tags":["domain"]}`
- **反例（高考）**：`y=√(x-1)/(x-3)` 求值域，不写 `x≥1 且 x≠3`。
- **反例（考研）**：`∫_0^1 √(x-x^2) dx`，配方后不检查被开方式在 `[0,1]` 上非负。

## T05 分母为零未排除

- **severity** / **默认扣分**：`major` / 2
- **触发条件**：题面或步骤出现分母含变量的分式（`/` 后接变量，或 `\frac{…}{…}` 的分母含字母），且无 `domain` tag。
- **检测依据**：文本正则；`steps[].tags`。
- **正确写法**：先声明分母不为零，再讨论。
  `{"text":"分母 x-1≠0，故定义域为 R\{1}。","tags":["domain"]}`
- **反例（高考）**：解 `1/(x-1)=2`，两边同乘 `x-1` 后直接得 `x=1.5`，不写 `x≠1`。
- **反例（考研）**：求 `y=(x^2+1)/(x^2-1)` 的值域，用判别式法时不排除 `x^2=1`。

## T06 单位遗漏

- **severity** / **默认扣分**：`minor` / 1
- **触发条件**：`contract.answer_format.units ≠ null`，且 `solution.answer.unit` 为空或与 `units` 字符串不相同。
- **检测依据**：`answer_format.units`；`solution.answer.unit`。
- **正确写法**：`answer.unit` 原样抄 `contract.answer_format.units`（如 `"cm^2"`），数值部分只放数字。也可在最终 step 打 `units` tag 复述。
- **反例（高考）**：立体几何求体积，答「`V = 8π`」，题面单位 `cm³`。
- **反例（考研）**：应用题算出需求量 `Q = 120`，题面单位为「万件」，答案未带。

## T07 多解遗漏

- **severity** / **默认扣分**：`major` / 2
- **触发条件**：`contract.verification.expected_solution_count` 存在，且大于 `answer.value` 按下列分隔符切分后的解个数：半角逗号 `,`、半角分号 `;`、**全角分号 `；`**、中文「或」。**缺省不判。**
- **检测依据**：`verification.expected_solution_count`；`answer.value` 按 `[,;；]|或` 切分后的非空段数。
- **正确写法**：答案写成可切分的集合形式并写全，如 `"x=π/6 或 x=5π/6"`，或把多解写进 `answer_format.type="set"`。
- **反例（高考）**：`sin x = 1/2`，`x∈[0,2π]`，只写 `π/6`，漏 `5π/6`。
- **反例（考研）**：`x^2 = 4` 在复数域内只写 `±2`，漏 `±2i`（题干已声明复数域时）。

## T08 参数范围未讨论

- **severity** / **默认扣分**：`major` / 2
- **触发条件**：`contract.givens` 任一项的 `symbol` **是单字符参数**、且属于集合 `a b c k m n p t λ θ`，且 `steps` 无 `param-range` tag。**不要求题面出现「参数」二字**——符号本身即声明。
- **检测依据**：`givens[].symbol`（单字符，裁剪空白后比对集合）；`steps[].tags`。
- **正确写法**：显式分类并打 tag。
  `{"text":"当 a>0 时…；当 a=0 时…；当 a<0 时…。","tags":["param-range"]}`
- **反例（高考）**：`f(x)=x^2-2ax` 在 `[0,1]` 上的最小值，直接当作对称轴 `x=a` 落在区间内。
- **反例（考研）**：讨论 `∫_1^∞ x^{-p} dx` 敛散性，只写 `p>1` 收敛，不讨论 `p≤1`。

## T09 区间端点开闭错误

- **severity** / **默认扣分**：`major` / 2
- **触发条件**：`answer_format.type = "interval"`，且契约提供端点开闭信息时，`answer.value` 的括号与之一致性检查失败：左端 `(` 必须配 open、`[` 配 closed；右端同理。**缺省不判。**
- **字段名（定稿）**：技能库统一写 **`answer_format.endpoints`（复数）**，形如 `{"left":"open","right":"closed"}`。**兼容旧写法 `answer_format.endpoint`（单数）**：契约里两者任给其一即可，同时给出时以 `endpoints` 为准。
- **检测依据**：`answer_format.endpoints`（回退 `answer_format.endpoint`）；`answer.value` 的首尾字符。
- **正确写法**：单调区间端点按「在该点有定义且填入不破坏单调性」决定开闭，并保证与 `endpoints` 字段一致。
- **反例（高考）**：`f(x)=x^3-3x` 的减区间写 `[-1,1]`，标准答案 `(-1,1)`（端点开闭看命题口径，但必须与契约一致）。
- **反例（考研）**：收敛域写 `(-1,1]`，幂级数在 `x=1` 发散时应为 `[-1,1)`。

## T10 充分必要混淆

- **severity** / **默认扣分**：`major` / 2
- **触发条件**：`goal.kind = "prove"`，`steps` 含 `iff` tag，但 `forward` 与 `backward` 只有一个出现。
- **检测依据**：`goal.kind`；`steps[].tags` 中的 `iff` / `forward` / `backward`。
- **正确写法**：双向都要写，分别打 `forward`（充分）与 `backward`（必要），并各自给独立依据。
- **反例（高考）**：证明「`a>1` 是 `f` 递增的充要条件」，只证「`a>1` ⇒ 递增」。
- **反例（考研）**：证明「`A` 可逆当且仅当 `|A|≠0`」，只写 `|A|≠0 ⇒ 可逆`。

## T11 循环论证

- **severity** / **默认扣分**：`blocker` / **0**（`basis=heuristic`，**永不扣分**；`defaultDeduct` 定稿为 0）
- **触发条件**：某 step 的 `text` 复述 `goal.statement` 的结论，且该 step 的 `evidence_refs` 为空、`tags` 里没有任何 `theorem:<name>`。
- **检测依据**：`goal.statement` 与 `step.text` 的包含/近似关系（文本启发式）。`detect` 只能返回 `basis:"heuristic"` 的 finding。
- **正确写法**：任何引用结论的位置，前面必须有已验证的独立依据；定理要写全适用条件。
- **反例（高考）**：证明「数列 `{a_n}` 单调递增」，中间写「由 `{a_n}` 递增可知 `a_{n+1}>a_n`」。
- **反例（考研）**：证明「`f` 在 `[a,b]` 上一致连续」，直接用「因为 `f` 连续故一致连续」，把待证结论当前提。

> 处理口径：命中 T11 时，主控必须在解答里补上独立依据或把该步标 `heuristic` 并降级为 `LowConfidence`；**不得**因为没有 `rule` 扣分就当它没发生。reason code 用 `EVIDENCE_CONFLICT`。

## T12 增根未检验

- **severity** / **默认扣分**：`major` / 2
- **触发条件**：`steps` 含 `square-both-sides` tag，且不存在 `check:extraneous` tag。
- **检测依据**：`steps[].tags`。
- **正确写法**：平方后必须代回原方程（或判号）验根，并显式写「经检验，`x=…` 为增根，舍去」。
  `{"text":"平方后代回原方程检验，x=-1 使左边为 1、右边为 -1，故舍去。","tags":["check:extraneous"]}`
- **反例（高考）**：`√(2x+3)=x` 平方得 `x=3` 或 `x=-1`，两个都写进答案。
- **反例（考研）**：三角方程两边平方后不检查周期性丢解/增解。

## T13 过早四舍五入

- **severity** / **默认扣分**：`minor` / 1
- **触发条件**：任一中间 `step.text` 含 `≈`，且 `answer_format.tolerance` 存在，最终答案的有效精度低于容差要求。
- **检测依据**：`steps[].text`；`answer_format.tolerance`；`answer.value` 的有效位数。
- **正确写法**：中间过程保留精确式（`π`、根式、分数），只在最后一步按容差取近似并写 `≈`。
- **反例（高考）**：概率题中间把 `1/3≈0.33` 代入再乘 3，最终答 `0.99`。
- **反例（考研）**：数值积分每步取 4 位小数累加，最终误差超出 `rel 1e-3`。

## T14 无结论句

- **severity** / **默认扣分**：`minor` / 1
- **触发条件**：`goal.kind = "prove"`，且 `steps` 无 `conclusion` tag。
- **检测依据**：`goal.kind`；`steps[].tags`。
- **正确写法**：末步收束，写「故……成立，证毕。」并打 tag。
  `{"text":"综上，存在 ξ∈(a,b) 使 f'(ξ)=(f(b)-f(a))/(b-a)，证毕。","tags":["conclusion"]}`
- **反例（高考）**：证明不等式，最后一行停在化简结果，没有「故原不等式成立」。
- **反例（考研）**：证明秩不等式，推完 `r(AB) ≤ min{r(A),r(B)}` 的中间式就结束。

## T15 符号未定义

- **severity** / **默认扣分**：`minor` / 1
- **触发条件**：`step.text` 使用未在 `contract.givens[].symbol` 或前序 `step.text` 中定义的符号（正则粗判：独立出现的拉丁单字母 `a-z`/`A-Z`，**以及希腊字母 `α-ω`、`Α-Ω`**，且未在该步首次赋值）。
- **说明**：希腊字母必须检测——`ξ`、`λ`、`θ`、`φ` 是证明与线代题最常见的未定义符号。
- **检测依据**：`givens[].symbol`；按 step 顺序累积的已定义符号表。
- **正确写法**：新符号首次出现时同句定义，如「设中点 `M(x_0,y_0)`」。
- **反例（高考）**：解析几何里直接用 `k` 表示斜率，而题面与前面都没定义 `k`。
- **反例（考研）**：证明里直接用 `ξ`，不写「由中值定理，存在 `ξ∈(a,b)`」。

## T16 选择题干扰项

- **severity** / **默认扣分**：`major` / 2
- **触发条件**：`contract.distractors` 存在，且 `answer.value`（去空白、统一大小写后）命中其中任一项。**缺省不判。**
- **检测依据**：`contract.distractors`；归一化后的 `answer.value`。
- **正确写法**：命中干扰项说明大概率落进了某个陷阱，必须回到 S4 重新验证，并在解答里说明为什么排除该选项。
- **反例（高考）**：求 `a` 的取值范围，答案选到「漏掉端点」的那个选项（如 `(0,1)` 而非 `[0,1]`）。
- **反例（考研）**：选择题算出的秩比正确值少 1，恰好是该题的干扰项。

## T17 条件未用尽

- **severity** / **默认扣分**：`major` / 2
- **触发条件**：`givens` 中 `required=true` 的条目，在 `steps` 中没有 `uses:<givenId>` 引用。
- **检测依据**：`givens[].id`、`givens[].required`；`steps[].tags` 里的 `uses:G1` 形式。
- **正确写法**：每个必用条件在首次使用时打 `uses:G1`，并在正文说明「由条件 G1（`f` 为奇函数）得……」。
- **反例（高考）**：题给「`f` 是定义在 `R` 上的奇函数」，解答只做求导，全程没用奇函数性质。
- **反例（考研）**：题给「`A` 是 3 阶正交矩阵且 `|A|=1`」，求特征值时不用 `|A|=1`。

## T18 计数重复/遗漏

- **severity** / **默认扣分**：`major` / 2
- **触发条件**：`contract.domain = "probability"`，**或**题面文本含「排列/组合/计数/种数/多少种」；且 `steps` 无 `cases:N` tag。
- **检测依据**：`domain`、`problem.text`、`steps[].tags`（不要求 `problem_type`）。
- **正确写法**：按互斥且完备的类别拆开，`cases:N` 的 N 等于类别数，最后求和或容斥并交代。
- **反例（高考）**：5 男 3 女选 4 人「至少 1 女」，只算 `C(8,4)-C(5,4)` 而不说明为什么这样扣。
- **反例（考研）**：把两封信投入 3 个信箱的样本空间数成 6 而不是 `3^2`。

## T19 独立性误用

- **severity** / **默认扣分**：`major` / 2
- **触发条件**：**先满足文本门槛**——`problem.text` 或任一 `givens[].text` 出现「独立」「条件概率」或形如 `P(AB)` 的乘积式；**再**要求在涉及 `P(AB)=P(A)P(B)` 或条件概率的步骤上没有 `independent` tag。
- **不触发的情形（重要）**：仅仅 `domain = "probability"` **不触发**。不放回抽样、古典概型、分布列求期望等题，题面没提独立性，就**不得**因为缺 `independent` tag 扣分——这类题本来就不需要该假设。
- **检测依据**：`problem.text`、`givens[].text` 的「独立」「条件概率」/`P(AB)`；`steps[].tags`；`steps[].text` 里的乘积式。
- **正确写法**：要么显式声明「由题意 `A`、`B` 相互独立」，要么用 `P(B|A)` 保持一般性。
  `{"text":"由各次射击相互独立，P(AB)=P(A)P(B)。","tags":["independent","uses:G2"]}`
- **反例（高考）**：甲、乙各射击一次，直接乘概率，题面只说「互不影响」之外没交代。
- **反例（考研）**：`P(A-B)=P(A)-P(AB)` 被写成 `P(A)(1-P(B))`，隐含独立性。

## T20 矩阵乘法顺序错误

- **severity** / **默认扣分**：`major` / 2
- **触发条件**：`contract.domain = "linear_algebra"`，且**同一个 step 的文本内**同时出现 `AB` 与 `BA` 型乘积、又未说明二者关系（如「`A`、`B` 可交换」）。**跨 step 不触发**——前一步写 `AB`、后一步写 `BA` 是正常推导。
- **检测依据**：`domain`；`steps[].text` 里的大写字母乘积模式。
- **正确写法**：保持书写顺序；转置、逆、相似变换都要按顺序写，`(AB)^T = B^T A^T`。
- **反例（高考/强基）**：写 `(AB)^T = A^T B^T`。
- **反例（考研）**：`A` 与 `B` 相似，写 `P^{-1}AP=B` 与 `PAP^{-1}=B` 混用。

## T21 行列式符号错误

- **severity** / **默认扣分**：`major` / 2
- **触发条件**：`contract.domain = "linear_algebra"` 且 `numeric_residual` 检查的 `status = "fail"`。
- **检测依据**：`proteus_verify` 产生的 numeric evidence。
- **正确写法**：按行/列展开时写全 `(-1)^{i+j}`，或用行列变换并记录每次变换的符号/倍数影响。
- **反例（高考/强基）**：3 阶行列式按第二行展开，漏掉代数余子式的符号因子。
- **反例（考研）**：`|kA| = k^n|A|` 写成 `k|A|`。

## T22 秩判断错误

- **severity** / **默认扣分**：`major` / 2
- **触发条件**：`contract.domain = "linear_algebra"` 且 `steps` 无 `rank` tag（凡涉及方程组解的存在性/唯一性、向量组相关性、相似判定的题都要求）。
- **检测依据**：`domain`；`steps[].tags`。
- **正确写法**：显式给出秩的等式/不等式链，并说明依据。
  `{"text":"r(A)=2，r(A|b)=3，故 r(A)<r(A|b)，方程组无解。","tags":["rank"]}`
- **反例（考研）**：直接写「`Ax=b` 有唯一解」，不给 `r(A)=r(A|b)=n`。
- **反例（考研）**：判断向量组相关性时凭直觉，不化阶梯形、不比较秩与个数。

## T23 收敛性未检验

- **severity** / **默认扣分**：`major` / 2
- **触发条件**：**先满足文本门槛**——`problem.text` 或任一 `step.text` 出现「级数」「收敛」「发散」之一；**再**要求 `steps` 无 `convergence` tag。
- **不触发的情形（重要）**：仅仅 `domain = "series"` **不触发**。高考数列题（等差/等比/裂项求和）即使把 `domain` 填成 `series`，只要题面不谈级数收敛，就不该扣 T23。
- **检测依据**：`problem.text`、`steps[].text` 的「级数/收敛/发散」；`steps[].tags`。
- **正确写法**：先判敛散再谈和；写清判据（比较、比值、根值、莱布尼茨）与适用条件。
  `{"text":"由比值判别法，lim |a_{n+1}/a_n| = 1/2 < 1，级数绝对收敛。","tags":["convergence"]}`
- **反例（考研）**：把 `Σ x^n` 逐项求和得 `1/(1-x)` 却不写收敛域 `|x|<1`。
- **反例（考研·判据误用）**：交错级数只验 `a_n→0` 就断言收敛（莱布尼茨还要求 `a_n` 单调递减）。

## T24 时间超限

- **severity** / **默认扣分**：`minor` / 0（**只标 reason，不扣分**）
- **触发条件**：`proteus_budget check` 返回 `phase = "exhausted"`，即 `remaining_s / budget_s ≤ 0.1`。
- **处理**：`TrapFinding` 照常产生（`deduct: 0`），同时在状态判定里强制：
  1. `Verified` 降级为 `LowConfidence`，reason code 追加 `TIME_EXHAUSTED`（§2.9-5）；
  2. 对外的「分值说明」必须写明「本分数基于时间耗尽前的证据，可能偏低」。
- **正确写法**：`salvage` 相位就把可得分步骤写完整，不要等到 `exhausted` 再补。
- **反例（高考）**：压哨停笔，解答只到「由题意得」；状态应为 `LowConfidence`，但不得因为超时扣分。
- **反例（考研）**：证明题写到一半时间到，仍把半成品标 `Verified`——这既违反 §2.9-5，也违反本技能的「无 formal 证据不得 Verified」纪律。
