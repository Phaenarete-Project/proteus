# 高考数学知识点大纲（GK.*）

用途：给 `ExamContract.knowledge_points` 供 ID、判是否超纲、判题型、给 `grading_rubric.step_points` 找踩分点。

**ID 规则**：`^[A-Z0-9]+(\.[A-Z0-9_]+)+$`，本文件全部为 `GK.<模块>.<节点>`。**禁止自造 ID**；表里没有的节点，先在此表补行再使用。

**怎么用**：
1. 一条契约的 `knowledge_points` 取 1–3 个**主干**节点，不要罗列所有沾边节点。
2. 「可考步骤分点」是建议分值，按 12 分题裁剪；写进契约时 `Σ step_points.points + answer_points` 必须等于 `total_points`（§2.1 `POINTS_SUM`）。
3. 「高频陷阱 ID」只是**该节点的提示**，不等于已判定；判定必须由 `detectTraps` 或 `proteus_grade` 产生。
4. 表外内容（如矩阵、微积分以外的大学内容、竞赛超纲工具）→ `syllabus.out_of_syllabus` 非空 → 状态 `OutOfSyllabus`。

**合计**：10 个模块，49 个节点。

## 附：模块与 domain 的映射（写契约时用）

| domain 枚举 | 覆盖本表模块 |
|---|---|
| `calculus` | 二 函数与导数、九 不等式（导数不等式部分） |
| `geometry` | 五 立体几何、六 解析几何、八 向量 |
| `probability` | 七 概率与统计 |
| `inequality` | 九 不等式 |
| `series` | 四 数列 |
| `complex` | 十 复数 |
| `other` | 一 集合与常用逻辑（也可归入 `other`） |

三角函数（三）通常归 `calculus`（与导数结合）或 `geometry`（解三角形）；**必须与 `domain` 的实际解法一致**，不要为凑矩阵格乱填。
