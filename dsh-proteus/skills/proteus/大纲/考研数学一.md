# 考研数学一知识点大纲（KY1.*）

用途：给 `ExamContract.knowledge_points` 供 ID、判是否超纲、判题型、找踩分点。考研数一 = 高等数学 + 线性代数 + 概率论与数理统计。

**ID 规则**：`^[A-Z0-9]+(\.[A-Z0-9_]+)+$`，本文件全部为 `KY1.<模块>.<节点>`。**禁止自造 ID**；表里没有的节点，先在此表补行再使用。

**前缀约定**：
- `KY1.CALC.*` = 高等数学（含空间解析几何，因其与多元微积分同属数一「高等数学」卷面）。
- `KY1.LINALG.*` = 线性代数。
- `KY1.PROB.*` = 概率论与数理统计。

**合计**：3 个模块群、21 个分组、79 个节点（CALC 35 / LINALG 23 / PROB 21）。
